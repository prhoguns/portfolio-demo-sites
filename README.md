# Portfolio Demo Sites

A shared collection of five fictional, client-ready business websites:

- North & Vale, a law firm
- Oak & Pearl Dental, a dental clinic
- Riva Studio, a hair salon
- Alder & Row, a real estate brokerage
- Brickline Build Co., a construction company

Each concept has three responsive pages and an interactive customer flow. The photography is sourced from Unsplash and is not AI-generated.

Serve this directory locally to open the collection page:

```bash
python3 -m http.server 4175
```
